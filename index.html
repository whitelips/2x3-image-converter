    원본 크기 그대로

    이미지를 확대·축소하거나 자르지 않습니다. 중앙에 배치하고 검은 여백을 더해 정확히 2:3으로 맞춥니다. 이미 2:3이면 원본 파일을 그대로 저장합니다.

    파일 형식 유지

    WebP와 PNG는 무손실 인코딩, JPEG는 최고 품질로 저장합니다. JPEG 재압축에는 손실이 발생할 수 있습니다. 변환된 파일은 sRGB로 처리되며 투명 영역은 검은색으로 채워지고 EXIF 등 메타데이터는 보존하지 않습니다.

    URL이 열리지 않나요?

    이미지 주소를 직접 입력해 주세요. 로그인이나 외부 접근 허용(CORS)이 필요한 서버에서는 불러오지 못할 수 있습니다. 이때 원본 다운로드를 시도합니다. 새 탭에 이미지가 열리면 직접 저장하고, 해당 항목의 ‘저장한 파일 첨부’를 눌러주세요. 첨부 후 변환은 자동으로 이어집니다. 다운로드 완료 여부는 확인할 수 없으며 외부 프록시는 사용하지 않습니다.

    알아두세요

    정지 WebP·PNG·JPEG를 지원합니다. 파일 수·용량·해상도에 별도의 제한을 두지 않습니다. 큰 이미지는 처리 시간이 길어지거나 기기의 메모리 부족으로 탭이 종료될 수 있습니다. 실제 처리 범위는 브라우저와 이미지 형식에 따라 달라집니다. 자동 저장이 차단되면 다운로드 버튼을 눌러주세요.
